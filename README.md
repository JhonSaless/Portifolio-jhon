# Portfólio Jhonata Sales

Site em React + TypeScript + Vite + Framer Motion.

## Rodar
```bash
npm install
npm run dev
```

## Publicar
```bash
npm run build
```
Suba o projeto no GitHub e importe na Vercel (framework Vite, build `npm run build`, saída `dist`).

## Personalizar
- Foto: adicione `public/jhonata.jpg` (substitui automaticamente o monograma no crachá).
- Currículo: `public/curriculo-jhonata.pdf`.
- Dados, textos, links e projetos: `src/App.tsx`.
- Estilos: `src/style.css`.

Os links individuais de projetos não foram inventados; configure-os quando existirem.
